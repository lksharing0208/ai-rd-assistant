# Database Design

## 执行步骤
1. 先读取现有 DDL、Entity、Mapper、迁移脚本和命名规范。
2. 明确主键、唯一约束、关联关系、索引、默认值和 NULL 语义。
3. 明确状态、创建/更新时间、软删除及用户/租户数据隔离。
4. 分析事务边界、并发更新、乐观锁/悲观锁和幂等约束。
5. 检查 SQL 条件、索引、分页、排序和批量操作。
6. 为迁移制定兼容部署、回滚和数据校验步骤。

## 输出
表结构/字段说明、DDL 与索引方案、SQL/ORM 映射、事务与并发设计、数据隔离和权限说明、迁移和回滚计划。

## 安全规则
- 不臆造数据库类型、字段或现有索引。
- UPDATE/DELETE 必须审查 WHERE 条件，避免全表误操作。
- 新字段说明类型、长度、NULL、默认值和用途。
- 线上迁移评估锁表、数据规模和版本兼容。
