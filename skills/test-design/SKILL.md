# Test Design

## 执行步骤
1. 从验收标准和代码变更提取可验证行为。
2. 选择测试层次：单元、集成、API、端到端、回归、性能或安全。
3. 覆盖正常、异常、边界、空值、重复、幂等、并发和权限场景。
4. 明确前置数据、Mock、环境依赖和清理方式。
5. 设计返回值、状态、数据库变化和事件等断言。
6. 使用项目已有测试框架、命名和目录约定。
7. 在可用环境执行测试并记录命令及结果。

## 用例字段
Case ID、需求/代码点、前置条件、输入/步骤、预期结果、数据校验、优先级。

## 报告
分别列出已执行且通过、已执行但失败、未执行及阻塞原因。
不得将代码阅读当作测试执行，不得伪造日志或覆盖率。
