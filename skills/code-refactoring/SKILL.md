# Code Refactoring

## 目标
在保持对外行为和业务语义不变的前提下改善结构。

## 执行步骤
1. 确认重构目标、范围、行为契约和禁止改变的语义。
2. 阅读目标代码及调用方、测试、配置和同类实现。
3. 识别重复逻辑、职责边界、依赖方向和副作用。
4. 设计最小重构步骤，优先小步、可回滚。
5. 实施后比较公开 API、状态流转、异常和事务行为。
6. 执行相关测试并审查最终 Diff。

## 规则
- 没有行为测试时先建立关键特征测试或明确风险。
- 不把重构与功能变更混在一个不可审查的大改动中。
- 不擅自更改接口、字段、状态值和事务边界。
- 不为了减少行数牺牲可读性。

## 输出
重构前后职责变化、文件清单、行为保持说明、测试结果和遗留风险。
