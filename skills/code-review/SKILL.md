# Code Review

## 范围
默认只审查本次变更。先看 Diff，再按需读取相关上下文；历史问题仅在影响当前变更时报告。

## 检查项
- 需求覆盖、正常/异常/边界路径、状态转换、空值和幂等。
- Java/Spring 分层、Bean、异常、NPE、事务和并发（适用时）。
- SQL 条件、参数映射、UPDATE/DELETE、逻辑删除、N+1 和索引（适用时）。
- 鉴权、越权、注入、敏感信息、日志凭证和输入校验。
- 性能退化、资源泄漏、重复调用、可维护性和测试缺口。

## 严重等级
- MUST_FIX：功能/数据错误、数据丢失、安全漏洞、严重性能问题或违反硬性规范。
- SHOULD_FIX：明显影响稳定性、维护性、测试性或性能的问题。
- OPTIONAL：低风险优化。

## 每条问题必须包含
- 文件路径和代码位置
- 问题及触发条件
- 业务/安全/运行影响
- 修改建议
- 可验证证据

## 规则
- 以代码事实为依据，不制造风格问题。
- 不重复报告同一根因。
- 未读取的代码不得作为问题证据。
- 无问题时明确输出“未发现需要修复的问题”。
