# API Design

## 执行步骤
1. 确认资源、动作、调用方、鉴权方式和兼容约束。
2. 定义路径、HTTP/RPC 方法、请求字段、响应字段和数据类型。
3. 明确必填、默认值、校验、分页、排序和过滤规则。
4. 统一错误码、错误结构、异常映射和幂等策略。
5. 明确用户/租户数据权限、审计和敏感字段脱敏。
6. 检查超时、重试、重复请求、限流和版本兼容。

## 输出
API 清单、请求/响应字段表、DTO/VO 约定、错误码和异常行为、鉴权/幂等/数据权限说明、兼容与版本策略。

## 规则
- 现有项目接口规范优先。
- 不臆造当前项目字段和错误码。
- 破坏性接口变更必须说明兼容和迁移方式。
